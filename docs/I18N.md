# Système d'Internationalisation (i18n)

## Vue d'ensemble

Le projet utilise maintenant un système d'internationalisation complet qui permet de supporter plusieurs langues. Par défaut, le script détecte automatiquement la langue du système.

## Langues supportées

- **Français** (`fr`) - Langue par défaut si votre système est configuré en français
- **English** (`en`) - Langue de fallback par défaut

## Utilisation

### Détection automatique

Le système détecte automatiquement la langue basée sur la variable d'environnement `LANG` :

```bash
# Système en français
export LANG=fr_FR.UTF-8
./install.sh  # Affichera en français

# Système en anglais
export LANG=en_US.UTF-8
./install.sh  # Affichera en anglais
```

### Forcer une langue

Vous pouvez forcer une langue spécifique avec la variable `LANG_CODE` :

```bash
# Forcer le français
LANG_CODE=fr ./install.sh

# Forcer l'anglais
LANG_CODE=en ./install.sh
```

## Ajouter des traductions

Pour ajouter une nouvelle langue, éditez `lib/i18n.sh` :

1. Ajoutez la détection de langue dans la section de configuration
2. Ajoutez toutes les clés de traduction avec le préfixe de langue

Exemple pour l'espagnol :

```bash
# Dans la section LANGUAGE CONFIGURATION
case "${LANG:-}" in
    es_*|ES_*) LANG_CODE="es" ;;
esac

# Dans la section TRANSLATION STRINGS
I18N_STRINGS["es.header.title"]="Script interactivo de instalación del servidor de correo"
I18N_STRINGS["es.progress.checking"]="Comprobando el progreso de instalación anterior..."
# ... etc
```

## Clés de traduction disponibles

### En-têtes
- `header.title` - Titre principal du script
- `header.subtitle` - Sous-titre

### Progression
- `progress.checking` - Message de vérification
- `progress.no_previous` - Pas d'installation précédente
- `progress.title` - Titre de la progression
- `progress.completed_steps` - Étapes complétées
- `progress.interrupted` - Installation interrompue
- `progress.resume_question` - Question de reprise
- `progress.resuming` - Message de reprise
- `progress.fresh_question` - Question nouvelle installation
- `progress.starting_fresh` - Démarrage nouvelle installation
- `progress.cancelled` - Installation annulée
- `progress.completed` - Installation complétée

### Installation
- `install.warning` - Avertissement de début
- `install.duration` - Durée estimée
- `install.interruptible` - Possibilité d'interruption
- `install.continue` - Confirmation pour continuer
- `install.completed` - Installation réussie

### Étapes
- `step.detect_system` - Détection du système
- `step.collect_info` - Configuration utilisateur
- `step.update_packages` - Mise à jour des paquets
- `step.install_core` - Installation des paquets essentiels
- `step.install_optional` - Installation des paquets optionnels
- `step.setup_database` - Configuration base de données
- `step.configure_postfix` - Configuration Postfix
- `step.configure_dovecot` - Configuration Dovecot
- `step.setup_ssl` - Configuration SSL
- `step.setup_autodiscover` - Configuration autodécouverte
- `step.install_webmail` - Installation webmail
- `step.finalize` - Finalisation

### Autres
- `skip.already_completed` - Étape déjà complétée (avec %s pour le nom)
- `prompt.press_enter` - Message "Appuyez sur Entrée"

## Fonction de traduction

La fonction `t()` est utilisée pour obtenir les traductions :

```bash
# Traduction simple
t "header.title"

# Traduction avec formatage (style printf)
t "skip.already_completed" "System detection"
```

## Normes de code

### Utilisation de `echo`

Pour maintenir la cohérence :

- **`echo -e`** : Pour afficher du texte avec couleurs/formatage
- **`echo -ne`** : Pour les prompts sans retour à la ligne
- **`echo ""`** : Pour les lignes vides (sans options)
- **`printf`** : Pour les valeurs de retour de fonctions

Exemples :

```bash
# Affichage avec couleur
echo -e "${GREEN}Success!${NC}"

# Prompt sans newline
echo -ne "${YELLOW}Question?${NC} "

# Ligne vide
echo ""

# Retour de fonction
printf "%s" "$result"
```

### Variables de couleur

Toujours utiliser les variables définies dans `lib/ui.sh` :

- `RED`, `GREEN`, `YELLOW`, `BLUE`, `MAGENTA`, `CYAN`, `WHITE`
- `NC` (No Color) pour réinitialiser
- `BOLD` pour le texte en gras

## Maintenance

Lors de l'ajout de nouveaux messages :

1. Ajoutez la clé dans `lib/i18n.sh` pour toutes les langues
2. Utilisez `t "votre.clé"` dans votre code
3. Testez avec différentes langues
4. Documentez la nouvelle clé dans ce README
